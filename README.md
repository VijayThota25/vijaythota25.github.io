# VIJAY: THE AI CHRONICLES

A cinematic, Netflix-inspired AI engineering portfolio built with editable HTML, CSS and JavaScript. This is an original recreation inspired by the described experience, not a fork of Sushmita Dasari’s repository.

## Preview locally

From this folder, run `python -m http.server 8000`, then open http://localhost:8000. A local server is required to load `portfolio-data.json`.

## Customize

- `portfolio-data.json`: all projects, architectures, outcomes, tech stacks and certificate filenames.
- `index.html`: page structure, contact details, experience timeline and professional summary.
- `styles.css`: theme, animations, layout and responsiveness.
- `app.js`: intro, profile selection, project carousels, modal case studies and certificate viewer.
- `assets/vijay.jpg`: portrait.
- `assets/Vijay_Thota_Resume.pdf`: downloadable resume.
- `assets/focusai.png`: screenshot.
- `assets/certificates/`: uploaded credential PDFs.

## Deploy

Upload the folder to a static hosting service such as Netlify, Vercel or GitHub Pages. The root should serve `index.html`.
